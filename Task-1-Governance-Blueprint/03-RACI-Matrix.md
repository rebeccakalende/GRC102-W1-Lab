# GHC Security Governance RACI Matrix

R = Responsible  
A = Accountable  
C = Consulted  
I = Informed

| Governance Activity | Board | CEO | InfoSec Governance | IT Manager | Compliance | HR / Finance / Dev |
|---|---|---|---|---|---|---|
| Security policy approval | A | C | R | C | C | I |
| Security risk review | I | A | R | C | C | C |
| Incident response planning | I | A | R | R | C | C |
| Security awareness & training | I | A | R | C | C | R |
| Regulatory compliance | I | A | C | C | R | C |
| Security performance reporting | A | C | R | C | C | I |
| Access management | I | I | A | R | C | C |
| Third-party security review | I | A | R | C | R | C |
